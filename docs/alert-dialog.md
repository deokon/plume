# Alert Dialog

Modal dialog specifically designed for alerting users to important information or actions.

## Properties

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `name` | `string` | `'alert-dialog'` | - |
| `show` | `bool` | `false` | - |
| `maxWidth` | `string` | `'2xl'` | - |
| `action` | `string` | `'Confirm'` | - |
| `withCancel` | `bool` | `true` | - |
| `onConfirm` | `string` | `''` | - |
