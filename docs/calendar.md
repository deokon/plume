# Calendar

A visual calendar interface for selecting dates.

## Properties

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `model` | `string` | `null` | - |
| `value` | `mixed` | `null` | - |
| `min` | `string` | `null` | - |
| `max` | `string` | `null` | - |
| `mode` | `string` | `'single'` | - |
| `onDateSelect` | `string` | `null` | AlpineJS expression to evaluate when a date is selected. Access selected value via `value`. |
