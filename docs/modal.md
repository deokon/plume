# Modal

A dialog box or popup window that is displayed on top of the current page.

## Properties

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `name` | `string` | `null` | - |
| `show` | `bool` | `false` | - |
| `maxWidth` | `string` | `'2xl'` | - |
| `title` | `string` | `null` | - |
