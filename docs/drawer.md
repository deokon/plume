# Drawer

A panel that slides in from the edge of the screen.

## Properties

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `name` | `string` | `null` | - |
| `show` | `bool` | `false` | - |
| `side` | `string` | `'right'` | - |
| `title` | `string` | `null` | - |
| `description` | `string` | `null` | - |
| `onOpen` | `string` | `null` | AlpineJS expression to evaluate when the drawer opens. |
| `onClose` | `string` | `null` | AlpineJS expression to evaluate when the drawer closes. |
