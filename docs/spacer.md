# Spacer

Fills available space in a flex container.

## Overview

The Spacer is a simple utility component that grows to fill available space along the main axis of a flex container.

## Usage

### In a Navbar

```blade
<div class="flex items-center w-full p-4 bg-secondary rounded-lg">
    <span>Brand Logo</span>
    <x-plume::spacer />
    <x-plume::button>Login</x-plume::button>
</div>
```
