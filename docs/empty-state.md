# Empty State

Use this component to show a placeholder when a list or page has no data.

## Properties

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `string` | `'No results found'` | - |
| `description` | `string` | `null` | - |
| `icon` | `string` | `'icon-[fluent--search-info-24-regular]'` | - |
