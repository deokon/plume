# Tabs Item

Individual tab navigation link.

## Properties

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `for` | `string` | `null` | The unique identifier of the tab this item activates. |
| `size` | `string` | `'md'` | The size of the tab: 'sm', 'md', 'lg'. |
| `style` | `string` | `'default'` | The visual style: 'default', 'secondary', 'error', 'outline', 'ghost', 'link', 'minor'. |
| `shape` | `string` | `'default'` | The shape of the tab button: 'default' (rounded), 'pill', 'round'. |
