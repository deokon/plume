# Kbd

Displays keyboard shortcuts or input keys with semantic styling.

## Properties

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `size` | `string` | `'md'` | Size of the component: 'sm', 'md', 'lg'. |

## Usage

```blade
<p>Press <x-plume::kbd>Ctrl</x-plume::kbd> + <x-plume::kbd>K</x-plume::kbd> to search.</p>
```
