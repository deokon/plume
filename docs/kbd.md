# KBD

Displays keyboard input.

## Overview

The KBD component is used to indicate keyboard shortcuts or specific key presses in documentation or UI hints.

## Properties

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `size` | `string` | `'md'` | `sm`, `md`. |

## Usage

### Simple Shortcut

```blade
<p>
    Press <x-plume::kbd>Ctrl</x-plume::kbd> + <x-plume::kbd>K</x-plume::kbd> to search.
</p>
```
