# Icon

Displays an icon using the Iconify library (specifically the Fluent set by default).

## Properties

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `i` | `string` | `null` | The full icon name (e.g., 'icon-[fluent--save-24-regular]'). |

## Usage

```blade
<x-plume::icon i="icon-[fluent--home-24-filled]" class="size-6 text-primary" />
```
