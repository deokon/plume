# Stepper Step

An individual step within a stepper component.

## Properties

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `step` | `int` | `null` | The step number (e.g., 1, 2, 3). |
| `title` | `string` | `null` | Primary title of the step. |
| `description` | `string` | `null` | Optional secondary description. |
| `prev` | `mixed` | `null` | Text for the previous button. |
| `next` | `mixed` | `null` | Text for the next button. |
