# Contributing to Plume

Thank you for your interest in contributing to Plume! As this is currently a personal project, please follow these guidelines if you're making local changes or suggestions.

## Development Workflow

1. Create a branch: `feature/` or `fix/`.
2. Follow the established coding standards (Tailwind, Blade, Laravel).
3. Ensure every component has corresponding dark mode styles.
4. Run tests: `composer test`.
5. Sync metadata: `php dev-scripts/sync_metadata.php`.

## Commits

Please use Conventional Commits (e.g., `feat:`, `fix:`, `chore:`).
